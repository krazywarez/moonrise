#+title: moonrise-server

Cloudflare Worker: SWPC polling every 5 minutes, =/v1/today=, device
registration, aurora pushes over APNs. D1 for storage.

* local
#+begin_src sh
wrangler d1 migrations apply moonrise --local
wrangler dev --test-scheduled
curl "http://localhost:8787/__scheduled?cron=*/5+*+*+*+*"
curl http://localhost:8787/v1/today
#+end_src

APNs cannot be reached from =wrangler dev= (no HTTP/2); test pushes
against a deployed Worker.

#+end_src

Launch Library 2's anonymous limit is per IP, and Workers share egress IPs,
so anonymous requests from Cloudflare often get HTTP 429. With an API key:

#+begin_src sh
wrangler secret put LL2_API_KEY
#+end_src

With the key, the launch in focus (T−60 to T+15) is polled every 2 minutes
(at most 31 requests an hour); without it, every 5 (at most 13).

* launch Live Activity channels
Launch Live Activities get status and NET changes over APNs broadcast
channels, one per launch and APNs environment, handed out a day before NET
from the =launch_channels= table (migration =0005_launch_channels.sql=).
Needs the Broadcast capability on for =sh.krz.moonrise= in the developer
portal.

With =APNS_MANAGE_CHANNELS= set to ="1"= (once =spikes/apns-channels= shows
the Worker reaches the management ports), the Worker creates and deletes
channels itself. Otherwise keep the pool filled from a computer; the log
says =launch channel pool empty= when it runs out.

#+begin_src sh
export APNS_KEY_PATH=AuthKey_644XS4F2RG.p8
node scripts/channels.ts create production 30 > pool.sql
node scripts/channels.ts create sandbox 30 >> pool.sql
wrangler d1 execute moonrise --remote --file pool.sql

# Ended more than 8 hours ago: delete at APNs, then the rows.
wrangler d1 execute moonrise --remote --command \
  "SELECT environment, channel_id FROM launch_channels WHERE ended_at < strftime('%Y-%m-%dT%H:%M:%fZ', 'now', '-8 hours')"
node scripts/channels.ts delete production <channel id>... > deleted.sql
wrangler d1 execute moonrise --remote --file deleted.sql
#+end_src

* API
| Method and path | Body / result |
|-
| =GET /v1/today= | ={spaceWeather: {kpNow, observedAt, kpNext24h, fetchedAt}}= |
| =GET /v1/launches?environment=sandbox= | ={fetchedAt, launches, recent}=; each launch has =channelId= for that APNs environment (default production) |
| =POST /v1/devices= | ={token, environment, band, utcOffsetMinutes, aurora?}=; band is a 5° geomagnetic latitude band, south negative |
| =DELETE /v1/devices/{token}= | |
| =GET /healthz= | feed status |
